# 半人工录入 — 操作说明

目标机：Windows + Chrome + 篡改猴。脚本 **0.5.0**，只在 `http://10.42.2.*` 运行。

**不做字段映射。** CSV 表头必须等于当前弹窗输入框的 `name`。交换机、路由器或其它设备，换一张表即可。

---

## 列多 / 列少

| 情况 | 行为 |
|---|---|
| CSV 有、本页弹窗没有 | 跳过（留给下一张表，例如构成） |
| 本页弹窗有、CSV 没有或空 | 不改这个控件 |
| 同名且有值 | 填入；「请选择」写不上则停下来让你点列表 |

`序号` / `备注` / `说明` / `编号` 不当作表单字段。

---

## 安装

篡改猴 → 添加新脚本 → 用 `dcinput.user.js` **全文覆盖**（v0.5.0）。

不确定表头时：打开该设备详情弹窗 → 面板 **「复制本页name」** 当作 CSV 第一行。

---

## 录入

1. 打开**该设备**的新建/详情弹窗。
2. 导入 CSV（Excel 另存 CSV 即可，认 GBK）。
3. **Alt+1** 填入本条。
4. 查询项按黄字点选 → 你点 **保存**。
5. 若弹出「是否继续…」：
   - 本行还有没填上的列 → 自动 **是**，等下一张表再填一次同名列
   - 本行列都已在当前表用完 → 自动 **否**
6. **Alt+2** 成功下一条，**Alt+3** 跳过。

账号整表只读时会提示换号。

---

## 快捷键

| 键 | 动作 |
|---|---|
| Alt+1 | 填入本条 |
| Alt+2 | 标记成功，下一条 |
| Alt+3 | 跳过，下一条 |
